# 🎯 Personal Job-Discovery Agent — Rugved

High-precision, multi-source job discovery engine for 2026 graduates (B.Tech IT, Entry Level, India, Product Tech Companies).

## System Architecture & Features
- **Multi-Source Ingestion**: Direct Official Career Portals (Amazon, Adobe, Nvidia, Salesforce, Target, Autodesk, Workday) + ATS Boards (Greenhouse, Lever, Ashby).
- **Sequential Hard Eligibility Gate**: Rejects non-tech, senior/staff/principal, foreign locations, mandatory PhD/Master's, and hard 1+ or 2+ YOE required minimums.
- **Telegram Bot (@RugvedJobBot)**: Instant updates, inline keyboard buttons, and Mark-As-Read tracking.
